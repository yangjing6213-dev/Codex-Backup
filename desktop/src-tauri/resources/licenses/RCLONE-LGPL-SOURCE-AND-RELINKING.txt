ENHE Codex Backup 0.1.7
rclone / github.com/cloudsoda/sddl corresponding source and relinking material

Purpose
-------
The installer contains rclone.exe. Its inspected Go build information links
github.com/cloudsoda/sddl at commit 926454e91efc95daf839e9112b09b6b2344c9e83.
That exact SDDL revision contains an LGPL-3.0 LICENSE while its README also
contains an MIT statement. The upstream repository is classified as
LGPL-3.0, so this package explicitly selects the LGPL-3.0 path for
redistribution and makes no MIT-only assumption. The README statement remains
recorded as an upstream documentation discrepancy.

Included source
---------------
RCLONE-LGPL-SOURCE-BUNDLE.zip contains:

* the rclone source at commit 687d264b689b8c49a67e2e52a8a5e0caa01c04ce
  (the v1.75.1 release commit), including go.mod and go.sum;
* the SDDL source at commit 926454e91efc95daf839e9112b09b6b2344c9e83,
  including its exact LICENSE and README;
* the build manifest used to identify the linked revisions and build inputs.

Relinking procedure
-------------------
1. Extract both source trees from RCLONE-LGPL-SOURCE-BUNDLE.zip.
2. In the rclone source tree, verify that go.mod requires the SDDL revision
   recorded in RCLONE-BUILD-MANIFEST.json and that go.sum is unchanged.
3. Put the SDDL source at the module path selected by Go, or use the normal Go
   module download mechanism to obtain the same revision and verify its hash.
4. With Go 1.26.8 or a compatible later Go 1.26 toolchain, run the relinking
   command recorded in RCLONE-BUILD-MANIFEST.json from the rclone source tree.
5. Replace rclone.exe only after reviewing the modified source and verifying
   the resulting binary and its notices.

The recorded flags and environment reproduce the observed build inputs; a
byte-for-byte identical executable is not promised because toolchain and
environment details can change. The rclone go.mod/go.sum files identify the
other module sources needed for a complete build. Their notices are included
in GO-THIRD-PARTY-NOTICES.txt.

License materials
-----------------
The installer also contains the GNU LGPL-3.0/GPL-3.0 texts and the complete
third-party notices. This file is a redistribution and engineering record,
not a legal opinion. The upstream SDDL LICENSE/README discrepancy is retained
for transparency; the package's distribution decision is the conservative
LGPL-3.0 path described above.
