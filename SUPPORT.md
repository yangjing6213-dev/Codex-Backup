# Support

Use GitHub Issues for reproducible questions and bug reports. Include the app
version, Windows version, expected behavior, actual behavior, and a redacted
diagnostic message. Do not attach `.codex` folders, `.rehome` packages,
conversation exports, credentials, or private project files.

The supported product scope is the Windows x64 local-first backup, restore,
offline migration, and bilingual settings flow described in the README. Live
OneDrive recovery, second-device migration, and original-session continuation
are not guaranteed by the current verification evidence.
