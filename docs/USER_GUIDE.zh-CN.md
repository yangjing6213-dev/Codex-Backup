# ENHE Codex Backup 中文使用说明

## 第一次使用

应用启动后先看“概览”。云端状态显示为“已关闭”是正常默认状态；这不会阻止本地项目发现、备份、历史浏览和恢复。

启动时应用会先读取已保存的配置，再扫描配置中的 Codex 数据位置。Codex 路径未配置时会尝试当前 Windows 用户的 `.codex`；找不到时会显示实际尝试路径，可直接点击“选择 Codex 数据位置”重新选择。随后应用会在本机固定磁盘后台发现项目候选，扫描只读取目录元数据，候选需要你勾选后才会进入备份范围。

如果遇到受保护的 Windows 目录，应用会安全跳过并只显示无权限目录数量，不会把几十条“拒绝访问”堆在页面中。需要时在“项目”勾选“扫描受限目录时申请管理员权限”，再点击“以管理员权限重新扫描”并按 UAC 提示操作。

1. 打开“项目”，勾选要纳入完整备份的项目；非 Git 普通目录可在“手动添加项目目录”中输入并加入，然后保存。
2. 打开“设置”，确认 Codex 数据位置和本地备份目录。点击字段旁的文件夹按钮即可打开 Windows 路径选择窗口；路径也可以手动输入，支持本机磁盘、移动盘或含中文/空格的目录。
3. 打开“备份与迁移”，输入恢复密码，点击“开始本地备份”。密码用于加密 restic 仓库，忘记密码无法恢复仓库。
4. 需要计划任务时勾选当前用户计划任务，并勾选“记住密码”。密码只用当前 Windows 用户的 DPAPI 保护；未记住密码时，计划任务无法读取密码并会报告错误。
5. 不熟悉流程时打开“操作说明”，按流程图从自动扫描一路完成到恢复或离线迁移。

备份期间关闭云端不会影响本地过程。应用只管理自己启动的 restic 子进程，不会扫杀其他程序。

## 查看和恢复

在“备份与迁移”点击“刷新本地备份”查看加密仓库中的快照。填写独立的“恢复目标目录”后，在对应快照上点击“恢复”。应用先恢复到私有暂存目录，校验 `enhe-payload` 和 manifest，再提交到 `backup-<id>` 目录。

如果目标已经存在，操作报告冲突并停止，不覆盖目标中的资料。恢复后的文件不会自动执行脚本、Git hooks 或 MCP 配置；请先检查内容，再自行打开项目。

## 完整备份范围

选中项目会保留项目文件、`.git`、未提交修改、未跟踪文件和能识别到的 worktree 元数据。Codex 数据位置中的活动/归档 JSONL、SQLite 主文件及 WAL/SHM 旁车文件、未归类内容和交接资料按文件保留；损坏或缺失内容会进入 manifest 的问题列表，不静默声称完整。

凭据、Cookies、私钥、`.env`（`.env.example` 除外）、依赖目录、缓存和运行时锁文件被排除。完整备份不会照搬 ReHome 对 `.git` 的排除规则。

## ReHome 迁移

“导出 ReHome 迁移包”和“导入 ReHome 迁移包”用于适用的离线设备迁移。它们依赖目标 Codex 的本地注册和迁移事务，和 restic 完整备份互不替代。导入前关闭目标 Codex；发生冲突时先查看计划，再选择保留目标或使用包内容。失败或取消应使用迁移记录中的回滚入口。

## 云端（可选）

云端默认关闭。要配置 OneDrive：

1. 在“设置”填写 rclone 配置文件、远端名称、OneDrive 路径和云端仓库路径。
2. 点击“开始 OneDrive 配置”，按向导出现的问题逐项回答。取消时不会启用云端，也不会上传快照。
3. 配置文件生成后仍需手动勾选“启用云端备份”并保存设置。
4. 只有点击“测试 OneDrive 连接”或某个快照的“上传此快照”时，应用才会启动远端操作。

本地备份不依赖云端。授权失效、断网、限流或超时只影响显式的云端操作；本地快照和历史保留在本机。

## 语言和外观

左侧语言按钮切换简体中文/English；设置中的外观可选浅色、深色或跟随系统。语言切换不会清除表单；键盘用户可以通过 Tab 到达导航、表单、错误和操作按钮。

## 常见错误

- “恢复密码必填”：没有传入密码，也没有可用的当前用户 DPAPI 密码。
- “仓库目录重叠”：本地仓库或恢复目录位于源资料内部，请更换到独立目录。
- “目标已存在”：选择新的恢复目标；应用不会覆盖原目标。
- “云端配置不完整”：先完成 OneDrive 配置并保存，再打开云端开关。
- “计划任务不可用”：当前用户任务计划未能注册或读取；本地手动备份仍可继续。
- “本机项目扫描已部分完成”：部分目录无权限、被跳过或扫描被取消；页面会给出聚合统计，已经发现的候选仍可手动勾选，不能把部分结果当作全盘完成。

离线标准 restic 恢复命令见 [离线恢复说明](OFFLINE_RESTORE.zh-CN.md)。当前实际验证边界见 [STATUS](STATUS.md)。
