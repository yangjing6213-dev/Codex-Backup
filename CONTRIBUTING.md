# Contributing

ENHE Codex Backup is an open-source beta. Bug reports are welcome when they include the app version, operating system, a redacted error message, and the affected local flow. Never attach a personal `.rehome` file, token, conversation export, or private project to a public issue.

For changes, keep Desktop behavior, package compatibility, and safety checks covered by focused tests. Do not weaken default exclusions for authentication data, secrets, browser state, or runtime files.
